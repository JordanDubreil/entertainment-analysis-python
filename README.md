# Entertainment Industry Trends Analysis

## Overview

This project analyzes trends in the entertainment industry using three datasets: MovieLens, Netflix, and IMDb. The goal is to explore patterns in genres, ratings, and content distribution across platforms.

## Datasets Used

* MovieLens (user ratings dataset)
* Netflix Titles dataset
* IMDb Top 1000 Movies dataset

## Key Features

* Data cleaning and preprocessing using Pandas
* Genre transformation using split and explode methods
* Average rating analysis by genre
* Cross-platform comparison using pivot tables
* Data visualization of trends

## Key Insights

* Documentary and Film-Noir genres showed the highest average ratings
* Comedy and Crime genres had lower average ratings
* Differences exist between user-based ratings (MovieLens) and broader audience ratings (IMDb)
* Netflix data highlights content distribution rather than ratings

## Tools Used

* Python (Pandas, NumPy)
* Jupyter Notebook
* Matplotlib / Seaborn

## Files

* `entertainment_trends_analysis.ipynb` → Main analysis notebook
* `project_report.docx` → Written report
